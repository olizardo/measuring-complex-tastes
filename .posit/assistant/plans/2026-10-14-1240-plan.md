## Design Goals

### fig-omega-demographics (primary figure, goes in main text)

**Purpose**: Show how demographic position shapes WHERE disagreement concentrates (genre-specific patterns)

**Design approach**:
- **Single integrated figure** showing 8 key genres × 5 demographics × 3 dimensions (240 data cells, but not all shown)
- **Small multiples** layout: 3 rows (one per dimension), 8 columns (key genres: rap, indie, dance/club, classical, opera, Broadway/musicals, big band, Latin/salsa)
- **Within each small multiple**: 5 bars (one per demographic category), color-coded (blue = above-mean disagreement, red = below-mean)
- **Visual hierarchy**: 
  - Genres ordered by dimension (Dim 1: rap/indie/dance/club left, classical/opera right; Dim 2: same ordering; Dim 3: granting genres left, withholding right)
  - Demographics ordered consistently left-to-right (age, parents' education, subjective class, race/ethnicity, gender)
- **Readability**:
  - Horizontal bars, not vertical (easier to read genre and demographic labels)
  - Genre and demographic labels bolded, larger font
  - Value labels on bars (r = -0.43, mean diff = +0.24)
  - Consistent color scale across all panels (NOT free scales)
  - 8.5" wide × 6–7" tall (fits in manuscript column width with room for caption)

### fig-omega-demographics-genres (supplementary figure)

**Purpose**: Detailed breakdown showing which genres dominate each demographic's disagreement signature

**Design approach**:
- **Heatmap-style matrix**: All 20 genres × 5 demographics × 3 dimensions
- **Color gradient**: Blue (positive/above-mean) to white to red (negative/below-mean), absolute scale
- **Value labels**: Only for |effect| > 0.10 (avoids clutter, highlights actionable patterns)
- **Dimension panels**: 3 separate heatmaps, side-by-side or stacked with clear dimension labels
- **Readable labels**: 
  - Genre names on rows (14–16 pt, not abbreviated)
  - Demographic categories on columns (bold, 12 pt)
  - Dimension title above each panel
- **Size**: 10–12" wide × 8" tall per dimension (may need to drop into appendix or go on separate page)

  ggplot(corr_main, aes(y = demographic, x = effect_size, fill = as.factor(sign(effect_size)))) +
    geom_col(width = 0.7, color = "grey20", linewidth = 0.4) +
    geom_text(aes(label = sprintf("%.2f", effect_size)),
              hjust = ifelse(effect_size > 0, -0.2, 1.2),
              size = 3.2, fontface = "bold", color = "grey10") +
    geom_vline(xintercept = 0, color = "grey40", linewidth = 0.5) +
    scale_fill_manual(values = c(`1` = "#2C5CA3", `-1` = "#C84E34"), 
                      guide = "none") +  # No legend, use caption to explain color
    facet_grid(demographic ~ genre + dimension, scales = "free_x") +
    theme_minimal(base_size = 11) +
    theme(
      panel.grid.minor = element_blank(),
      panel.grid.major.x = element_line(color = "grey90", linewidth = 0.2),
      panel.grid.major.y = element_blank(),
